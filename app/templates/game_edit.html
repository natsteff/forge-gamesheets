Game artwork

Choose a custom image

Recommended: keep artwork with the game

For the best balance of quality and storage, use a square 1024 × 1024 WebP named icon.webp at the top level of the game’s library folder, then rescan. PNG and JPEG are also supported, and cover may be used instead of icon. Forge creates an optimized WebP display cache without changing the source image.

Web upload alternative: Uploading here stores an app-managed copy in Forge’s writable data folder, not in the read-only library. It overrides detected folder artwork and must be included with application-data backups. Use this when you cannot add an image to the source library.

PNG, JPEG, or WebP up to 25 MB and 40 megapixels. All artwork is center-cropped when it is not already square. Uploaded images are saved as 1024 × 1024 WebP; detected library artwork is cached at 512 × 512 for display.
