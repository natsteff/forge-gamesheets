What do these counts mean?
  • Indexed PDFs: Source PDFs recorded by the latest library scan.
  • Current reprints: Stored copies that match the recorded source, reprint format, and QR destination.
  • Missing reprints: Accessible source PDFs without a stored generated copy.
  • Out-of-sync reprints: Existing copies that need regeneration because the recorded source PDF, reprint format, QR destination, or generated file has changed.
  • Source unavailable: Indexed source PDFs that cannot currently be located or safely accessed, regardless of whether a generated copy exists. Restore access and rescan before generating their reprints.

Source availability is checked when this page loads; source changes are recorded by a library scan. Counts are recalculated when you return here after an operation.
