GameSheet basics

About Sheet Designer

Sheet Designer creates portable GameSheets for score tracking, reference information, checklists, and notes. It works best for structured, single-page layouts made from full-width or side-by-side sections.

FGS v1 is not a general page-layout or spreadsheet tool. It does not currently support free positioning, images, custom formulas, multiple pages, or pixel-perfect copies of existing documents.

GameSheets can be exported as printable PDFs. Compatible score sheets can also become temporary interactive LiveSheets.

Tip: An LLM can draft an FGS file from a score-sheet image or PDF when given the FGS v1 specification. Review and verify the result before importing it, and only share source documents you are permitted to upload.

Configure LiveSheet

LiveSheet uses this reusable GameSheet to create temporary digital scoring sessions. Scores and player names are never saved in the FGS source.

Enabling LiveSheet does not create or freeze a separate copy. Every new session automatically uses the latest saved version of this GameSheet; changes made later in Sheet Designer apply to future sessions.

Rows named Total and Grand Total are calculated automatically. Add at least one score table before enabling LiveSheet.
