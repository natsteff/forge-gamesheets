Access control

Trusted-operator mode: anyone who can reach this installation can edit it. Upgrading does not automatically activate authentication.

To create the first Admin and immediately require sign-in, open a terminal on the Docker host, change to this installation's Compose directory, and run:

docker compose exec app python -m app.accounts create-admin

Enter the Admin username and passphrase at the private prompts. There is no default password or web-based initial setup. See the accounts setup and recovery guide before enabling accounts on a non-local installation. Configure and test the final HTTPS proxy address first; remote HTTP sign-in is rejected.
